## Кратко о материалах

В папке `oopcpp` лежат ответы на теоретические вопросы и решения практических заданий по C++: виртуальные функции, виртуальный деструктор, приведение типов, сокрытие имени, трассировка программы и иерархия фигур.

В папке `testirovanie` лежат ответы по тестированию: случаи, когда тестирование не доказывает корректность, методы выявления противоречий в требованиях, требования к тест-кейсу, разделы тест-плана, а также практические задания на Python и C++ с чек-листами, тест-кейсами и unit-тестами.
